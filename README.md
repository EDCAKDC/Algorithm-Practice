## Purpose

This repository records hands-on problem-solving practice in Python. It is intentionally kept as a **working archive**: individual files preserve solutions to numbered programming problems and document the progression of algorithmic thinking over time.

For cleaner reusable implementations and computational-biology-oriented algorithm examples, see **[algorithm-playground](https://github.com/EDCAKDC/algorithm-playground)**.

## Repository Organization

Most solution files are named by problem number:

```text
1.py
102.py
124.py
200.py
...
1631.py
```

Each file is intended to be self-contained and easy to revisit independently.

## What This Repository Represents

This is a **practice repository rather than a software package or research project**. Its purpose is to strengthen:

- algorithmic problem decomposition
- Python implementation fluency
- data-structure selection
- time- and space-complexity awareness
- translation of mathematical logic into working code
